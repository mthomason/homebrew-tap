# Michael Thomason's Homebrew Tap

Official [Homebrew](https://brew.sh) tap for [**MAD Designer**](https://github.com/mthomason/MAD) — an open-source ad-hoc SQL query builder, banded report layout designer, and viewer for macOS (`AppKit`).

## Install

```sh
brew install --cask mthomason/tap/mad-designer
```

Or tap first and then install:

```sh
brew tap mthomason/tap
brew install --cask mad-designer
```
